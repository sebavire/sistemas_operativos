⚡ Actividad de Extensión: Encabezados Dinámicos y Reporte de Estado

Si ya terminaste la versión básica de gestor_usuarios.sh: Aplica las siguientes dos modificaciones para enriquecer la información mostrada en los visores de texto y agregar una nueva función de diagnóstico.

1. Encabezados Dinámicos en Funciones

Consigna: Modifica tus funciones para que los reportes no muestren únicamente un título estático. Deben incluir metadatos del sistema generados en el momento exacto en que se ejecuta la consulta.

El encabezado escrito en el archivo temporal debe contener:

  • El usuario actual que ejecuta el script (obtenido con el comando whoami o la variable $USER).
  • La fecha y hora de generación (obtenida con el comando date).

Sintaxis de referencia (Inclusión de comandos en cadenas con subshell):

echo " $(comando)" >> /tmp/archivo.tmp

2. Nueva Opción: Estado General del Sistema

Consigna: Agrega una nueva función al inicio del script llamada reporte_estado() e intégrala como una nueva opción en el menú de whiptail y en la evaluación del case.

Esta función debe combinar la salida de múltiples comandos en un solo reporte:

  • Nombre del equipo / Host (comando hostname).
  • Tiempo encendido del servidor (comando uptime -p).
  • Resumen de memoria RAM disponible y utilizada (comando free -h).
💡 Recordatorio: Recuerda usar > únicamente para la primera línea del archivo temporal para sobrescribir consultas anteriores, y >> para concatenar los demás comandos en orden secuencial antes de abrir la ventana --textbox.
