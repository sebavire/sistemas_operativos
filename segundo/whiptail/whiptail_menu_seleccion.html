Práctico: Selección de Opciones y Tareas Múltiples

Nuevo proyecto: Crea un archivo nuevo llamado config_servidor.sh. Aprenderemos a usar listas de selección única (radio buttons) y selección múltiple (checkboxes). Las ventanas se mostrarán en secuencia: primero la Parte 1 y, al finalizar esta, la Parte 2.

PARTE 1: Selección Única con Radiolist (--radiolist)

Consigna: Al iniciar el script, presenta un menú --radiolist donde el usuario solo pueda elegir una de las siguientes opciones para consultar el servidor:

  • Opción 1 - Espacio en disco: Usa el comando df -h /
  • Opción 2 - Memoria RAM: Usa el comando free -h
  • Opción 3 - Conectividad de red: Usa el comando ping -c 4 google.com

Guarda la selección en una variable, evalúala con una estructura case y muestra el resultado del comando en un --msgbox.

Sintaxis de referencia (Creación y evaluación de un Radiolist numérico):

OPCION=$(whiptail --title "Título" --radiolist "Seleccione una alternativa:" 15 60 3 \ "1" "Descripción de opción 1" ON \ "2" "Descripción de opción 2" OFF \ "3" "Descripción de opción 3" OFF 3>&1 1>&2 2>&3) case "$OPCION" in "1") RESULTADO=$(comando1) whiptail --title "Resultado" --msgbox "$RESULTADO" 12 60 ;; "2") RESULTADO=$(comando2) whiptail --title "Resultado" --msgbox "$RESULTADO" 12 60 ;; esac
Prueba tu script. Otorga permisos (chmod 700 config_servidor.sh) y verifica que la opción elegida ejecute su comando correspondiente antes de pasar a la Parte 2.

PARTE 2: Selección Múltiple con Checklist (--checklist)

Consigna: A continuación de la Parte 1, agrega un cuadro --checklist que permita al usuario marcar una o varias tareas de diagnóstico simultáneamente usando la barra espaciadora:

  • Opción 1 - Usuarios conectados: Usa el comando who
  • Opción 2 - Nombre del equipo: Usa el comando hostname
  • Opción 3 - Tiempo activo: Usa el comando uptime

Evalúa qué casillas fueron marcadas buscando el número correspondiente dentro de la variable devuelta y muestra los resultados en ventanas --msgbox.

Sintaxis de referencia (Creación y evaluación de un Checklist numérico):

SELECCIONADOS=$(whiptail --title "Título" --checklist "Marque las opciones necesarias con Espacio:" 15 60 3 \ "1" "Descripción de opción 1" OFF \ "2" "Descripción de opción 2" OFF \ "3" "Descripción de opción 3" OFF 3>&1 1>&2 2>&3) # Para verificar si una opción fue marcada, se busca el número dentro de la variable: if [[ "$SELECCIONADOS" == *"1"* ]]; then RES1=$(comando1) whiptail --title "Opción 1" --msgbox "$RES1" 10 50 fi if [[ "$SELECCIONADOS" == *"2"* ]]; then RES2=$(comando2) whiptail --title "Opción 2" --msgbox "$RES2" 10 50 fi
