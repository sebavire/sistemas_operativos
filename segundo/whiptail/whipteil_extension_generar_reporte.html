Actividad de Extensión: Refactorización del Reportador

Si ya terminaste y probaste la versión básica de config_servidor.sh, realiza las siguientes modificaciones en el código para mejorar el flujo del programa y la visualización de los datos.

1. Bucle de Ejecución Continuo y Opción de Salida

Consigna: Modifica la estructura de tu script para que no finalice automáticamente tras ejecutar un comando. Debe mantenerse en bucle (usando while true) mostrando los menús hasta que el usuario elija explícitamente la opción de finalizar.

  • Agrega la Opción 4: "Salir del programa" tanto en la Parte 1 (--radiolist) como en la Parte 2 (--checklist).
  • Si el usuario selecciona la opción 4 o presiona Cancelar, el script debe ejecutar la instrucción break o exit para cerrar de forma limpia.

2. Implementación de Visor Navegable (--textbox)

Consigna: Las ventanas --msgbox se quedan cortas cuando un comando genera muchas líneas de texto. Sustituye todos los --msgbox por ventanas --textbox.

💡 A tener en cuenta: La caja --textbox no admite variables directamente; exige la ruta de un archivo real almacenado en el disco.

Para lograrlo, debes redirigir la salida del comando de Linux a un archivo temporal dentro del directorio /tmp y luego invocar el visor apuntando a ese archivo.

Sintaxis de referencia (Redirección a archivo y lectura con textbox):

# 1. Se guarda la salida del comando en un archivo temporal con > comando > /tmp/reporte.txt # 2. Se muestra el archivo usando --textbox (permite desplazar con flechas) whiptail --title "Visor de Salida" --textbox /tmp/reporte.txt 15 70

3. Limpieza de Archivos Temporales

Consigna: Asegúrate de incluir la eliminación del archivo temporal (usando rm -f /tmp/reporte.txt) justo antes de que el programa finalice por completo, para evitar acumular archivos innecesarios en la carpeta /tmp.
