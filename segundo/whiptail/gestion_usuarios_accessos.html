🛠️ Actividad: Gestor de Usuarios y Accesos

Consigna: Crea un nuevo archivo llamado gestor_usuarios.sh. El objetivo es construir un panel interactivo de administración utilizando whiptail, estructurado mediante funciones, control de bucle repetitivo while true y manejo de archivos temporales en /tmp.

1. Requisitos de Funciones

El código debe ser modular. Debes definir al inicio del script las siguientes funciones con nombres representativos:

  • Listar usuarios del sistema: Muestra los nombres de los usuarios registrados utilizando el comando cut -d: -f1 /etc/passwd y los usuarios activos con who.
  • Espacio de directorios personales: Muestra el tamaño utilizado en las carpetas de los usuarios usando el comando du -sh /home/*.
  • Últimos ingresos al sistema: Consulta el historial de inicios de sesión ejecutando el comando last -n 10.
  • Función de limpieza y salida: Elimina el archivo temporal generado en /tmp, muestra un cuadro de diálogo de despedida con whiptail y finaliza la ejecución con exit 0.

Sintaxis de referencia (Estructura genérica de una función con encabezado y redirección):

# Estructura genérica para generar reportes en archivos temporales mi_funcion() { # 1. Se crea o sobreescribe el archivo con el encabezado inicial (>) echo "=== TITULO ===" > /tmp/archivo_USUARIO.tmp echo "" >> /tmp/archivo_USUARIO.tmp # 2. Se concatena el resultado del comando al final del archivo (>>) comando >> /tmp/archivo_USUARIO.tmp # 3. Se muestra la salida acumulada en el visor whiptail --title "Título de Ventana" --textbox /tmp/archivo_USUARIO.tmp 15 70 }

2. Menú Principal y Control de Flujo

El programa principal debe ejecutarse dentro de un bucle while true presentando un menú interactivo con whiptail (puedes usar --menu o --radiolist).

💡 Sugerencia: Revisa el código de la actividad anterior config_servidor.sh o consulta la guía de la actividad Menú de Selección para reutilizar la estructura base del menú.

El menú debe contar con las siguientes 4 opciones:

  1. Ver lista de usuarios registrados
  2. Consultar almacenamiento en /home
  3. Ver historial de últimos accesos
  4. Salir del programa

Sintaxis de referencia (Estructura modular del case):

# Dentro del bucle while true: case "$SELECCION" in "1") funcion_tarea_1 ;; "2") funcion_tarea_2 ;; "3") funcion_tarea_3 ;; "4") limpiar_y_salir ;; esac
