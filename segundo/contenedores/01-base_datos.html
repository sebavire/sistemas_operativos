Introducción a Contenedores - Base de Datos (MariaDB) e Interfaz Web (phpMyAdmin)

🔍 Consulta tu Puerto Asignado

Escribe tu usuario del servidor Linux para consultar tu puerto:

RED INTERNA PODMAN: mi_red
📦 phpMyAdmin Interfaz Web Gráfica
── (PMA_HOST=db_PUERTO) ──►
📦 MariaDB Motor de Base de Datos
▼ (Persistencia de datos)
📁 Carpeta ~/datos_db
🌐 Acceso Web Exterior: http://192.168.2.245:PUERTO/

Paso 1: Preparar la Carpeta para Datos Persistentes

Antes de lanzar el servidor de base de datos, debes crear una carpeta en tu directorio personal (~) llamada datos_db para almacenar la información de las tablas.

Utiliza el comando de consola correspondiente para crear esta carpeta.

Paso 2: Crear la Red Interna de Podman

Para que la base de datos y la interfaz web se comuniquen entre sí por su nombre dentro del servidor, crea una red aislada:

podman network create mi_red

(Si la terminal indica que la red ya existe, continúa al siguiente paso).

Paso 3: Levantar el Contenedor de Base de Datos (MariaDB)

Inicia MariaDB dentro de la red aislada, definiendo la contraseña del administrador (root), creando la base inicial, enlazando la carpeta de datos e indicando que el servicio se reinicie automáticamente si se cae:

podman run -d --restart always --net mi_red --name db_PUERTO -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=mi_base -v ~/datos_db:/var/lib/mysql:Z mariadb
  • Sustituye PUERTO por tu número de puerto asignado.
  • El parámetro -v ~/datos_db:... vincula la carpeta que creaste en el Paso 2 con el contenedor.
  • El parámetro --restart always garantiza que la base de datos siga corriendo aunque ocurra una falla.

Paso 4: Levantar la Interfaz Gráfica (phpMyAdmin)

Ejecuta phpMyAdmin en la misma red, conectándolo a tu contenedor de base de datos (db_PUERTO) y configurando la política de reinicio:

podman run -d --restart always --net mi_red -p PUERTO:80 --name admin_PUERTO -e PMA_HOST=db_PUERTO phpmyadmin
📷 Entregable 1: Ejecuta en la terminal el comando podman ps -a y toma una captura de pantalla donde se observe que ambos contenedores están en estado Up y con la política de reinicio activa.

Paso 5: Acceso y Verificación en phpMyAdmin

1. Abre el navegador web e ingresa a tu dirección asignada:

http://192.168.2.245:PUERTO/

2. Inicia sesión en el panel con las credenciales de la base de datos:

  • Servidor / Host: (dejar por defecto)
  • Usuario: root
  • Contraseña: root

3. Comprueba en el menú lateral izquierdo que se encuentre disponible la base de datos generada (mi_base).

📷 Entregable 2: Captura de pantalla del navegador web mostrando el panel principal de phpMyAdmin con tu sesión abierta correctamente.
