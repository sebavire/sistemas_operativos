5. Ve a la pestaña Insertar en la barra superior y carga al menos 2 o 3 registros.

Paso 2: Destrucción del Contenedor

Abre la terminal de Linux en tu servidor y ejecuta el siguiente comando para forzar la eliminación del contenedor de la base de datos:

podman rm -f db_PUERTO
⚠️ Comprobación: Vuelve al navegador web y refresca la página de phpMyAdmin. Verás que la interfaz indica un error de conexión porque el servicio de base de datos fue destruido.

Paso 3: Resurrección y Verificación de Persistencia

Recrea el contenedor de la base de datos vinculando la carpeta personal ~/datos_db para comprobar si los datos sobrevivieron:

podman run -d --restart always --net mi_red --name db_PUERTO -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=mi_base -v ~/datos_db:/var/lib/mysql:Z mariadb

Regresa a phpMyAdmin, refresca el navegador e inicia sesión nuevamente.
