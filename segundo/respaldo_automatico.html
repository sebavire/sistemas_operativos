📦 Actividad: Sistema de Respaldos Automáticos

📌 Escenario de Trabajo

Como administradores del servidor Rocky Linux, debemos garantizar que la carpeta Auditoria_Sistema (creada la clase pasada) se respalde de forma periódica, se mantenga protegida contra accesos no autorizados y no termine saturando el espacio en disco con archivos viejos.

🛠️ Consigna

1. Creación del Script de Respaldo

Crea un script llamado backup_sistema.sh en tu carpeta personal. Este script debe realizar tres acciones:

  • Asegurar que exista una carpeta destino llamada ~/Respaldos.
  • Empaquetar y comprimir la carpeta Auditoria_Sistema dentro de ~/Respaldos. El archivo resultante debe incluir la fecha y hora actual en su nombre (ejemplo: backup_2026-08-03_10-30.tar.gz).

💡 Ejemplos de referencia para la Tarea 1:

Para crear una carpeta sin que el sistema arroje un error si ya existe: 
mkdir -p /ruta/de/la/carpeta
Para crear un empaquetado comprimido con la fecha actual incluida en el nombre: 
tar -czf ~/mi_archivo_$(date +%Y-%m-%d_%H-%M).tar.gz /ruta/origen

2. Protección de la Copia de Seguridad (Permisos)

Agrega líneas al final de tu script backup_sistema.sh para que, justo después de crear el respaldo, modifique los permisos de la carpeta ~/Respaldos y del paquete generado. El objetivo es que únicamente tu usuario (el dueño) tenga todos los accesos (lectura, escritura y ejecución) y se le deniegue todo acceso al grupo y a otros usuarios del servidor.

💡 Ejemplo de referencia para la Tarea 2:

Para asignar permisos totales al dueño y restringir completamente al resto (notación octal): 
chmod 700 /ruta/al/archivo_o_directorio

3. Mantenimiento y Limpieza de Respaldos Viejos

Agrega una instrucción al final de tu script para evitar que el servidor se llene de archivos. El script debe buscar dentro de ~/Respaldos y eliminar automáticamente los archivos de respaldo que tengan más de 7 minutos de creados.

💡 Ejemplo de referencia para la Tarea 3:

Para buscar y eliminar archivos con una extensión específica que tengan más de 5 minutos de antigüedad: 
find /ruta/de/carpeta -name "*.tar.gz" -mmin +5 -delete

4. Automatización con Cron

Una vez que probaste el script manualmente y verificaste que funciona, configúralo en la tabla de tareas programadas (crontab) para que el servidor lo ejecute automáticamente cada 2 minutos.

💡 Ejemplo de referencia para la Tarea 4:

Estructura de una línea de crontab para ejecutar un comando/script cada 5 minutos: 
*/5 * * * * /ruta/completa/a/tu/script.sh

✅ Verificación de Autonomía

Comprueba por ti mismo el correcto funcionamiento del sistema antes de finalizar:

  1. Deja pasar unos minutos y revisa la carpeta ~/Respaldos con el comando ls -l ~/Respaldos.
  2. Verifica si los permisos de la carpeta y archivos muestran exclusivamente rwx------ (equivalente a 700).
  3. Comprueba que nunca existan más de 3 archivos .tar.gz almacenados al mismo tiempo en la carpeta de respaldos.
