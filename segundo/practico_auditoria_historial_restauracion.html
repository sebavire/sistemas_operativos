🔍 Actividad de Extensión: Auditoría e Historial de Restauración

Objetivo: Evolucionar el script de recuperación para que informe sus acciones en pantalla, sea resistente a fallos de carpetas inexistentes y guarde un registro histórico.

PASO 1: Reporte Visual en Pantalla

Abre tu script restaurar.sh y modifícalo para que muestre mensajes informativos durante su ejecución:

  1. Imprime un encabezado inicial en la terminal que indique el comienzo del proceso.
  2. Muestra en pantalla el contenido actual de la carpeta de prueba ~/Prueba_Restauracion antes de descomprimir.
  3. Ejecuta la descompresión del respaldo más reciente (lo que ya tenías programado).
  4. Imprime un mensaje final de cierre y vuelve a mostrar el contenido de la carpeta para confirmar que los archivos aparecieron.
📌 Ejemplos de referencia:
Mostrar un mensaje de texto en pantalla: 
echo "=== TEXTO A MOSTRAR ==="
Listar los archivos de un directorio específico: 
ls /ruta/del/directorio

PASO 2: Prueba de Resistencia ("Directorio Vacío")

Un buen script de administración debe funcionar incluso si la carpeta destino fue borrada por error.

  1. Elimina por completo la carpeta ~/Prueba_Restauracion desde tu terminal para simular la falla. (rm -rf carpeta)
  2. Asegúrate de que tu script contenga la instrucción para crear esa carpeta automáticamente si no existe (usando mkdir -p).
  3. Ejecuta tu script restaurar.sh.
  4. Verifica que la carpeta se volvió a crear sola y que los archivos se restauraron correctamente sin arrojar errores.
📌 Ejemplo de referencia:
Crear un directorio garantizando que no tire error si ya está creado: 
mkdir -p /ruta/del/directorio

PASO 3: Registro Histórico (Log de Auditoría)

Agrega instrucciones al final de tu script para llevar un registro automático de cada restauración realizada:

  1. Cada vez que se ejecute el script, debe agregar una línea con la fecha y hora exacta dentro de un archivo de registro llamado historial_restauraciones.log (ubicado en tu carpeta personal).
  2. Ejecuta el script de restauración 2 o 3 veces seguidas.
  3. Comprueba con el comando de lectura correspondiente que el archivo acumule todas las ejecuciones realizadas.
📌 Ejemplos de referencia:
Guardar un texto adjuntando la fecha actual al final de un archivo sin borrar el contenido anterior (operador >>): 
echo "mensaje: $(date)" >> ~/archivo.log

✅ Verificación Final

  • ¿El script muestra en pantalla el "antes" y el "después" de la carpeta?
  • ¿Si borras la carpeta de prueba, el script la recrea sin fallar?
  • ¿El archivo historial_restauraciones.log tiene guardadas las fechas de cada prueba?
