Actividad 3: Control de Errores y Validación ("Modo Pro")

En las actividades anteriores logramos capturar datos con --inputbox y procesarlos. Ahora reforzaremos el script menu_control.sh para evitar que falle si el usuario deja campos vacíos o presiona Cancelar.

🔍 El Problema a Resolver

Abre tu script e intenta presionar <Aceptar> sin escribir nada dentro del --inputbox de la Opción 5 o 6. Verás que el programa intenta ejecutar la orden con una variable vacía, generando un mensaje de error o un comportamiento inesperado.

1. Validación de Entradas Vacías

Consigna: Modifica la Opción 5 (Saludo) y la Opción 6 (Ping)[cite: 2] utilizando una estructura condicional. Si la variable no contiene ningún texto, el script debe mostrar una ventana de alerta advirtiendo el error y regresar al menú principal[cite: 1].

Ejemplo: Comprobación de variable vacía con -z

Usa este patrón genérico para verificar si una variable no tiene contenido antes de continuar:

if [ -z "$DATO" ]; then whiptail --title "Error" --msgbox "No ingresaste ningún dato o cancelaste la operación." 10 50 else COMANDO=$(comando "$DATO") whiptail --title "Respuesta" --msgbox "Resultado: $COMANDO" 10 50 fi

2. Personalización de Mensajes de Error

Consigna: Asegúrate de que el mensaje dentro del --msgbox de error sea específico según la opción donde se produjo el fallo (ejemplo: "Debe ingresar un nombre válido" para la Opción 5, o "Debe ingresar una IP o dominio para realizar el ping" para la Opción 6[cite: 2]).
