🚨 Actividad: Restauración de Respaldos en Linux

Objetivo: Recuperar los archivos del respaldo dentro de una carpeta de prueba sin modificar la carpeta original.

PARTE 1: Prueba de Comando Manual

  1. Crea una carpeta vacía en tu directorio personal llamada: ~/Prueba_Restauracion
  2. Identifica el nombre de uno de los archivos .tar.gz que se crearon en tu carpeta ~/Respaldos.
  3. Ejecuta en la terminal el comando para descomprimir ese paquete únicamente dentro de la carpeta ~/Prueba_Restauracion.
  4. Verifica con ls ~/Prueba_Restauracion que los archivos recuperados aparecieron allí.
📌 Ejemplo de referencia:
Descomprimir un paquete .tar.gz en una carpeta de destino específica (opción -C): 
tar -xzf /ruta/archivo_backup.tar.gz -C /ruta/destino/

PARTE 2: Automatización con Script

Crea un script llamado restaurar.sh que realice las siguientes acciones de forma automática al ejecutarlo:

  1. Asegure que exista la carpeta ~/Prueba_Restauracion (usa mkdir -p).
  2. Busque cuál es el archivo de respaldo más reciente dentro de ~/Respaldos.
  3. Descomprima ese último respaldo automáticamente en la carpeta ~/Prueba_Restauracion.
  4. Muestre un mensaje en pantalla que diga: "Restauración completada con éxito."
📌 Ejemplo de referencia:
Obtener la ruta del archivo más reciente en una carpeta y guardarlo en una variable: 
ultimo_archivo=$(ls -t /ruta/de/carpeta/*.tar.gz | head -n 1)
Para usar esa variable en el comando tar: tar -xzf "$ultimo_archivo" -C ...
