Control de Acceso y Confirmación

Actividad: Crea un archivo llamado seguridad.sh. Aprenderemos a capturar contraseñas y condicionar acciones con ventanas de confirmación.

PARTE 1: Autenticación con Contraseña (--passwordbox)

Consigna: Al iniciar seguridad.sh, solicita una clave mediante --passwordbox. Si la contraseña ingresada es igual a admin123, muestra una ventana --msgbox informando que el acceso fue concedido. De lo contrario, muestra un mensaje de error y finaliza el programa.

Sintaxis de referencia (Captura oculta y comparación de texto):

DATO_OCULTO=$(whiptail --title "Título" --passwordbox "Mensaje:" 10 50 3>&1 1>&2 2>&3) if [[ "$DATO_OCULTO" == "palabra_clave" ]]; then # ... Acciones si la clave coincide ... else # ... Mensaje de error con --msgbox ... fi
Prueba tu script. Antes de continuar a la Parte 2, dale permisos de ejecución (chmod 700 seguridad.sh) y verifica que valide correctamente la clave.

PARTE 2: Confirmación de Acción (--yesno)

Consigna: Únicamente si la contraseña fue correcta, el script debe preguntar mediante una ventana --yesno si el usuario desea consultar la fecha y hora del sistema. Si responde Sí, ejecuta el comando date y muestra su salida dentro de un --msgbox. Si responde No, muestra un aviso de operación cancelada.

Sintaxis de referencia (Evaluación de respuesta Yes/No):

if whiptail --title "Título" --yesno "¿Pregunta?" 10 50; then # ... Código a ejecutar si presiona SÍ ... else # ... Código a ejecutar si presiona NO ... fi
