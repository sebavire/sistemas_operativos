🧩 Actividad: Menú de herramientas

Objetivo: Crear un script con un menú interactivo que permita ejecutar tres herramientas útiles en el servidor.

📌 Consigna

Crea un script llamado menu_herramientas.sh que muestre un menú con las siguientes opciones:

# Menú de herramientas
1. Inventario del servidor
2. Saludo
3. Creador de carpetas
4. Salir
Elige una opción:

📋 ¿Qué debe hacer cada opción?

  • Opción 1 – Inventario: Muestra la fecha, el nombre del servidor, los usuarios conectados y el espacio libre en disco.
  • Opción 2 – Saludo: Pregunta tu nombre y muestra un saludo personalizado con la fecha y hora actual.
  • Opción 3 – Creador de carpetas: Crea una carpeta llamada actividad y dentro: docs, scripts y backup.
  • Opción 4 – Salir: Muestra un mensaje de despedida y termina el script.

⭐ Parte Extra (opcional)

Agrega un bucle while para que el menú se repita hasta que el usuario elija la opción "Salir".

🧪 Ejemplos

📌 Leer una variable con read

Para preguntar algo al usuario y guardar su respuesta:

read -p "¿Qué día es hoy?: " dia
echo "Hoy es $dia"

📌 Menú con case

El case permite ejecutar diferentes comandos según la opción que elija el usuario.

Estructura básica:

case $opcion in
    1) 
        echo "Has elegido la opción 1"
        date
        ;;
    2) 
        echo "Has elegido la opción 2"
        whoami
        ;;
    *) 
        echo "Opción inválida" 
        ;;
esac

¿Cómo funciona?

  • Si el usuario elige 1, se ejecutan todos los comandos que están entre 1) y ;;.
  • Si elige 2, se ejecutan los comandos entre 2) y ;;.
  • El *) se ejecuta si el usuario elige cualquier otra opción no contemplada.

Un ejemplo:

echo "1. Ver fecha"
echo "2. Ver quién soy"
read -p "Elige una opción: " opcion

case $opcion in
    1) 
        echo "La fecha actual es:"
        date
        ;;
    2) 
        echo "Tu nombre de usuario es:"
        whoami
        ;;
    *) 
        echo "Opción no válida. Elige 1 o 2." 
        ;;
esac

📌 Bucle while (para la parte extra)

Para repetir el menú hasta que el usuario elija salir:

opcion=0
while [ $opcion -ne 3 ]; do
    echo "1. Ver fecha"
    echo "2. Ver quién soy"
    echo "3. Salir"
    read -p "Elige una opción: " opcion

    case $opcion in
        1) date ;;
        2) whoami ;;
        3) echo "¡Hasta luego!" ;;
        *) echo "Opción no válida" ;;
    esac
done

📋 Comandos útiles para las opciones

date → muestra la fecha y hora
hostname → muestra el nombre del servidor
who → muestra los usuarios conectados
who | wc -l → cuenta los usuarios conectados
df -h / → muestra el espacio libre en disco
mkdir -p → crea carpetas
read -p → pide datos al usuario
echo "un texto" → muestra texto en pantalla
