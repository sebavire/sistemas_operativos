🧩 Actividad: Procesos

Objetivo: Crear un nuevo script que muestre los procesos más exigentes del servidor.

📌 Recordatorio de comandos

Conectarse al servidor:

ssh usuario@192.168.2.245

Subir un archivo a tu carpeta web:

scp archivo.sh usuario@192.168.2.245:/var/www/html/usuario/

Dar permisos de ejecución a un script:

chmod 755 /var/www/html/usuario/archivo.sh

Ejecutar un script y guardar su salida en un archivo:

/var/www/html/usuario/archivo.sh > /var/www/html/usuario/archivo.txt

📋 PARTE 1: Script de procesos

Crea un script llamado procesos.sh que muestre los procesos que más CPU están usando en el servidor.

Ejemplo del comienzo del script:

#!/bin/bash
echo "=== TOP 5 PROCESOS POR CONSUMO DE CPU ==="
echo ""

Luego, el script debe ejecutar los siguientes comandos:

  • ps aux --sort=-%cpu | head -6 → lista los 5 procesos que más CPU usan (el head -6 incluye la cabecera y los 5 procesos).
  • ps aux --sort=-%mem | head -6 → lista los 5 procesos que más memoria RAM usan.

La salida del script debe guardarse en un archivo llamado procesos.txt dentro de tu carpeta web.

📤 Subir el script y probarlo

  1. Sube el script al servidor con scp.
  2. Dale permisos de ejecución con chmod 755.
  3. Ejecutalo y guarda la salida en procesos.txt.
  4. Verifica desde el navegador que el archivo se creó:
http://192.168.2.245/usuario/procesos.txt

📋 PARTE 2: Mejorar el script de diagnóstico

Agregaremos más información al script de diagnóstico (diagnostico.sh).

Incluye:

  • Un título que diga "Información del sistema" (usando echo).
  • El comando uname -a (muestra información del kernel y el sistema operativo).
  • El comando whoami (muestra el nombre del usuario actual).

📤 Subir el script modificado y verificar

  1. Modifica diagnostico.sh en tu computadora, y súbelo al servidor.
  2. O Modificalo directamente en el servidor.
  3. Espera 2 minutos (el tiempo de cron) y recarga el archivo estado.txt en el navegador.
http://192.168.2.245/usuario/estado.txt

Deberías ver la nueva información al final del archivo.

🎯 Extra

Programa procesos.sh en cron para que se actualice automáticamente.

Agregá una nueva línea en tu crontab:

*/5 * * * * /var/www/html/usuario/procesos.sh > /var/www/html/usuario/procesos.txt

Espera 5 minutos y verifica que procesos.txt se actualiza.
