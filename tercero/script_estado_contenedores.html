Actividad: Script de Monitoreo de Contenedores

Para no tener que recordar ni escribir comandos largos cada vez que quieras saber si tus sitios web o base de datos están funcionando, vas a crear tu propio script ejecutable.

Paso 1 Crear el archivo del script

Paso 2 Escribir la estructura del script

Dentro del editor nano, escribe las siguientes líneas:

  1. En la primera línea, indicá el intérprete de script: 
    #!/bin/bash
  2. Agregá un comando echo para imprimir un título visual en pantalla que diga "Estado de mis contenedores". Por ejemplo:
  3. A continuación, agregá el comando para consultar la tabla detallada de tus contenedores: 
    podman ps -a --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"

Paso 3 Guardar el archivo

Una vez escritas todas las líneas en el editor:

  • Presioná Ctrl + O para guardar.
  • Presioná Enter para confirmar el nombre del archivo.
  • Presioná Ctrl + X para salir del editor nano.

Paso 3 Dar permisos de ejecución

Guarda y da permisos de ejecución con el comando chmod:

chmod 700 mis_contenedores.sh

Paso 5 Probar el script

Ejecuta el script:

./mis_contenedores.sh
