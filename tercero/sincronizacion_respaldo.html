🔄 Actividad Práctica: Sincronización Eficiente con rsync

📌 Referencia de la herramienta

Comando Descripción
rsync -avz ~/origen/ ~/destino/ Sincroniza el contenido del directorio origen hacia el destino.
rsync -avz --delete ~/origen/ ~/destino/ Elimina en el destino los archivos que ya no existen en el origen.
⚠️ Atención a la barra final (/): Poner origen/ sincroniza el contenido de la carpeta. Omitir la barra (origen) copia la carpeta entera.

📋 BLOQUE A: Preparación de directorios

  1. Accede al servidor por SSH desde PowerShell.
  2. Crea un directorio llamado origen_datos y una subcarpeta llamada documentos dentro de él.
  3. Usando el editor nano, crea dos archivos de texto:
    • origen_datos/nota1.txt
    • origen_datos/documentos/informe.txt
  4. Crea una carpeta vacía llamada destino_copia donde guardaremos la sincronización.

📋 BLOQUE B: Práctica de sincronización incremental

  1. Primera copia (Copia completa inicial):
    Ejecuta el comando rsync con las opciones -avz para sincronizar el contenido de origen_datos/ hacia destino_copia/.
    Observa la salida en la terminal: verás que transfiere todos los archivos creados.
  2. Comprobación del destino:
    Verifica con el comando de listado el contenido de la carpeta destino_copia/ para confirmar que los archivos están allí.
  3. Prueba de cambio (Sincronización incremental):
    Crea un nuevo archivo llamado nota2.txt dentro de origen_datos/ usando nano.
  4. Segunda copia:
    Vuelve a ejecutar exactamente el mismo comando de rsync que en el paso 1.
    Observa detenidamente la terminal: ¿Qué archivos se transfirieron esta vez?

📋 BLOQUE C: Manejo de eliminaciones (Efecto espejo)

  1. Elimina el archivo nota1.txt de tu carpeta origen_datos/.
  2. Ejecuta nuevamente el comando rsync -avz origen_datos/ destino_copia/.
  3. Revisa el contenido de destino_copia/. El archivo nota1.txt sigue existiendo allí porque la sincronización por defecto no elimina datos en el destino.
  4. Ahora ejecuta el comando agregando la opción de borrado:
    rsync -avz --delete origen_datos/ destino_copia/
  5. Verifica nuevamente la carpeta destino_copia/ para confirmar qué ocurrió con el archivo eliminado.

🚀 BLOQUE D: Automatización con Script y Cron

  1. Crea un script llamado sincronizar.sh en tu directorio personal usando nano.
  2. Escribe dentro del script la orden para sincronizar origen_datos/ hacia destino_copia/ manteniendo el efecto espejo (--delete).
    📌 Nota para Cron: Dentro del script, utiliza las rutas absolutas completas (ejemplo: /home/usuario/origen_datos/) para evitar fallos de ejecución.
  3. Otorga permisos de ejecución a tu script (chmod 700 sincronizar.sh).
  4. Abre la tabla de tareas programadas con el comando crontab -e.
  5. Configura una regla para que el script sincronizar.sh se ejecute automáticamente **cada 1 minuto** (sintaxis: * * * * *).
  6. Comprobación final: Crea un archivo prueba_cron.txt dentro de ~/origen_datos/. Espera un minuto sin tocar la terminal y verifica si el archivo apareció de forma automática dentro de ~/destino_copia/.
