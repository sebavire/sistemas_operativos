🔍 Desafío: Auditoría y Reinicio de Servicio Web

Escenario: Un proceso web no autorizado o antiguo está ocupando tu puerto personal asignado. Tu objetivo como administrador es auditar el puerto, identificar el identificador de proceso (PID), finalizarlo y desplegar tu propia instancia limpia del servicio.

Paso 1: Auditar el Puerto Ocupado

1. Ejecuta el filtro en la tabla de puertos usando tu número asignado (reemplaza PUERTO por el tuyo, ej: 8081):

sudo ss -tulpn | grep ':PUERTO'

2. Comprueba que el servicio actual responde a la red:

curl -I http://localhost:PUERTO/
✍️ Responde a partir de la salida en pantalla:
  • ¿Qué número figura dentro del paréntesis en la columna Process al final de la línea del comando ss? Anota ese número de PID: _________
  • ¿Qué código de estado HTTP devuelve el comando curl en su primera línea?

Paso 2: Finalizar el Proceso Previo

1. Envía la señal de terminación inmediata al proceso utilizando el PID que anotaste en el Paso 1:

sudo kill -9 PID_ANOTADO

2. Verifica que el puerto quedó liberado:

sudo ss -tulpn | grep ':PUERTO'
✍️ Comprobación de Liberación:
¿Qué devuelve la terminal al ejecutar de nuevo el comando ss tras aplicar el kill?

Paso 3: Desplegar tu Servidor Limpio

1. Inicia tu propia instancia del servidor web en tu puerto asignado, enviándolo al segundo plano mediante el símbolo &:

python3 -m http.server PUERTO &

2. Confirma la conectividad con tu nuevo servicio:

curl -I http://localhost:PUERTO/
✍️ Comprobación Final:
  • Al presionar Enter tras el comando de Python, la terminal muestra un número entre corchetes [1] seguido de un número. ¿Cuál es el nuevo PID de tu servicio?
  • ¿Qué respuesta obtienes con el comando curl final?
