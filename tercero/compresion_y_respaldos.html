🛠️ Actividad: Compresión y Respaldos

Objetivo: Practicar el uso de comandos para comprimir y descomprimir archivos en la terminal, y aplicar estos comandos dentro de un script funcional.

📌 Comandos base (Pizarrón)

Acción Estructura del comando
Comprimir una carpeta tar -czf nombre_archivo.tar.gz carpeta/
Descomprimir un archivo tar -xzf nombre_archivo.tar.gz
Ver el contenido sin descomprimir tar -tzf nombre_archivo.tar.gz

📋 BLOQUE A: Comandos en la terminal

Utilizando los comandos del cuadro anterior, realiza las siguientes tareas en tu terminal:

  1. Crea una carpeta llamada compresion_respaldos en tu directorio personal.
  2. Crea un archivo de texto llamado notas.txt dentro de la carpeta compresion_respaldos y escribe un mensaje breve en su interior.
  3. Comprime la carpeta compresion_respaldos generando un archivo llamado respaldo.tar.gz.
  4. Ejecuta el comando correspondiente para verificar qué archivos hay dentro de respaldo.tar.gz sin descomprimirlo.
  5. Elimina la carpeta original compresion_respaldos.
  6. Restaura la carpeta descomprimiendo el archivo respaldo.tar.gz.
  7. Comprueba con el comando de listado que la carpeta y el archivo recuperado están presentes.

📋 BLOQUE B: Crear el script

Aplica los conceptos trabajados para construir un script de respaldo:

  1. Crea un archivo de script llamado generar_respaldo.sh
  2. Escribe el script de forma que cumpla con las siguientes acciones al ejecutarse:
    • Muestre un mensaje en pantalla anunciando el inicio del proceso.
    • Comprime tu carpeta de usuario (ubicada en /home/usuario/) creando un archivo llamado respaldo_usuario.tar.gz.
    • Muestre un mensaje final en pantalla confirmando que terminó.
  3. Otorga los permisos de ejecución necesarios al script.
  4. Ejecútalo y comprueba en la terminal que el archivo respaldo_usuario.tar.gz fue creado con éxito.
