Paso 1: Auditar y Limpiar el Entorno

1. Verifica si tienes contenedores corriendo o detenidos en tu sesión:

podman ps -a

2. Elimina cualquier contenedor previo para evitar conflictos de nombres o puertos ocupados:

podman rm -f -a

Paso 2: Crear la Red Interna de Podman

Para que los contenedores puedan comunicarse directamente entre sí por su nombre, crearemos una red virtual aislada:

podman network create mi_red

(Si la terminal responde que la red ya existe, continúa normalmente).

Paso 3: Levantar el Contenedor de Base de Datos (MariaDB)

Inicia la base de datos MariaDB dentro de la red aislada, definiendo la contraseña de administrador (root), la base inicial y montando tu carpeta personal:

podman run -d --net mi_red --name db_PUERTO -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=mi_base -v ~/datos_db:/var/lib/mysql:Z mariadb
  • Reemplaza PUERTO por tu número de puerto asignado.
  • El parámetro -v ~/datos_db:... garantiza la persistencia de tus tablas en el servidor.

Paso 4: Levantar la Interfaz Gráfica (phpMyAdmin)

Ejecuta phpMyAdmin en la misma red e indica en la variable PMA_HOST el nombre de tu contenedor de base de datos (db_PUERTO):

podman run -d --net mi_red -p PUERTO:80 --name admin_PUERTO -e PMA_HOST=db_PUERTO phpmyadmin
📷 Entregable 1: Captura de pantalla de la terminal mostrando la ejecución de podman ps con ambos contenedores en estado Up.

Paso 5: Acceso y Verificación en phpMyAdmin

1. Abre el navegador e ingresa a tu dirección web asignada:

http://192.168.2.245:PUERTO/

2. Inicia sesión en el panel de phpMyAdmin con las credenciales de MariaDB:

  • Servidor / Host: (dejar por defecto)
  • Usuario: root
  • Contraseña: root

3. Verifica en la barra lateral izquierda que aparezca la base de datos creada automáticamente (mi_base).
