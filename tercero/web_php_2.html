Despliegue del Segundo Sitio Web

En este desafío desplegaremos un **segundo sitio web independiente** (Directorio de Clientes) conectado a la misma base de datos de actividades anteriores.

utiliza los comandos de la Ficha Técnica elaborada en la actividad anterior..

🔍 Consulta tus Puertos Asignados

Ingresá tu nombre de usuario para obtener tus puertos y parámetros exactos:

Paso 1 Base de Datos: Crear Tabla Clientes

1. Ingresá a tu phpMyAdmin desde el navegador usando tu Puerto Base.

2. Seleccioná tu base de datos mi_base, andá a la pestaña SQL y ejecutá:

CREATE TABLE IF NOT EXISTS clientes (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(100) NOT NULL,
    telefono VARCHAR(30) NOT NULL,
    ciudad VARCHAR(50) NOT NULL
);

Paso 2 Crear Directorio y Archivo PHP

1. En la terminal del servidor, crea la carpeta para el nuevo sitio:

mkdir ~/sitio_clientes

2. Crea el archivo index.php dentro de esa carpeta:

nano ~/sitio_clientes/index.php

3. Pega el siguiente código (Atención: reemplazá db_PUERTO por el nombre de tu contenedor de base de datos obtenido en el buscador de arriba):

<?php
$host     = 'db_PUERTO'; // <-- Reemplazar por tu contenedor (Ej: db_8098)
$usuario  = 'root';
$password = 'root'; 
$base_db  = 'mi_base';

$conn = new mysqli($host, $usuario, $password, $base_db);

if ($conn->connect_error) {
    die("<h2 style='color:red;'>Error de Conexión: " . $conn->connect_error . "</h2>");
}
?>
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Directorio de Clientes</title>
    <style>
        body { font-family: Arial, sans-serif; margin: 30px; background-color: #f4f6f9; color: #1e2a3a; }
        h1 { color: #0b5c3b; }
        .estado { padding: 10px; background-color: #d1e7dd; color: #0f5132; border-radius: 5px; font-weight: bold; }
        table { width: 100%; border-collapse: collapse; margin-top: 20px; background: white; }
        th, td { border: 1px solid #ccc; padding: 10px; text-align: left; }
        th { background-color: #0b5c3b; color: white; }
        tr:nth-child(even) { background-color: #f8f9fa; }
    </style>
</head>
<body>
    <h1>👥 Directorio de Clientes del Sistema</h1>
    <div class="estado">Conexión Exitosa a la Base de Datos</div>

    <table>
        <thead>
            <tr>
                <th>ID</th>
                <th>Nombre Completo</th>
                <th>Correo Electrónico</th>
                <th>Teléfono</th>
                <th>Ciudad</th>
            </tr>
        </thead>
        <tbody>
            <?php
            $resultado = $conn->query("SELECT * FROM clientes");
            while($row = $resultado->fetch_assoc()) {
                echo "<tr>
                        <td>" . $row["id"] . "</td>
                        <td><strong>" . $row["nombre"] . "</strong></td>
                        <td>" . $row["email"] . "</td>
                        <td>" . $row["telefono"] . "</td>
                        <td>" . $row["ciudad"] . "</td>
                      </tr>";
            }
            $conn->close();
            ?>
        </tbody>
    </table>
</body>
</html>

Paso 3 Desplegar el Contenedor con Podman

Consulta tu Ficha Técnica y despliega el nuevo contenedor ajustando los siguientes parámetros según tus datos consultados:

  • Nombre del contenedor: web_clientes_TU_PUERTO
  • Puerto asignado: Rango 81XX
  • Carpeta montada: ~/sitio_clientes
  • Red: mi_red
  • Política de reinicio: Incluir --restart always

No olvides habilitar la extensión mysqli dentro del nuevo contenedor:

podman exec -it web_clientes_PUERTO docker-php-ext-install mysqli

Paso 4 Comprobación Final

Ingresá desde el navegador web a tu sitio de clientes usando el puerto 81XX asignado. Si todo es correcto, verás la tabla de clientes cargada exitosamente.
