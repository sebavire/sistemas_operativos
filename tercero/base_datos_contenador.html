🛢️ Base de Datos (MariaDB) e Interfaz Web (phpMyAdmin)

🔍 Consulta tu Puerto Asignado

Escribe tu usuario de Linux (o el de tu compañero si trabajan en pareja) para consultar tu puerto:

ENTORNO DE USUARIO EN EL SERVIDOR
📦 phpMyAdmin Interfaz Web Gráfica
── (Red interna) ──►
📦 MariaDB Motor de Base de Datos
▼ (Guarda datos)
📁 Carpeta ~/datos_db
🌐 Acceso Web: http://IP_DEL_SERVIDOR:PUERTO/

Paso 1: Auditar y Limpiar el Puerto

1. Verifica si tu puerto está ocupado por alguna prueba anterior:

sudo ss -tulpn | grep ':PUERTO'

2. Si la consulta devuelve algún proceso activo, libéralo inmediatamente:

sudo fuser -k PUERTO/tcp

3. Vuelve a comprobar que el puerto haya quedado completamente libre.

Paso 2: Crear el Directorio para la Base de Datos

Para garantizar que los datos guardados en la base de datos persistan en el disco del servidor:

1. Crea un directorio llamado datos_db dentro de tu carpeta de usuario en el servidor.

Paso 3: Levantar el Contenedor de Base de Datos (MariaDB)

Ejecuta el contenedor del motor de base de datos definiendo la contraseña estándar (root), la base de datos inicial y montando tu carpeta local:

podman run -d --name db_PUERTO -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=mi_base -v /home/USUARIO/datos_db:/var/lib/mysql:Z mariadb
  • Reemplaza PUERTO por tu número asignado.
  • Reemplaza USUARIO por tu nombre de usuario de Linux.

Paso 4: Levantar la Interfaz Gráfica (phpMyAdmin)

Para publicar el panel de control web en tu puerto asignado, ejecuta el contenedor de phpMyAdmin conectado a la red interna del servidor:

podman run -d -p PUERTO:80 --name admin_PUERTO -e PMA_HOST=127.0.0.1 --net=host phpmyadmin
📷 Entregable 1: Captura de pantalla de la terminal mostrando la ejecución del comando y el ID del contenedor generado.

Paso 5: Acceso y Verificación en phpMyAdmin

1. Abre el navegador web en tu computadora e ingresa a la siguiente URL:

http://IP_DEL_SERVIDOR:PUERTO/

2. Inicia sesión en el panel gráfico de phpMyAdmin utilizando las siguientes credenciales:

  • Usuario: root
  • Contraseña: La clave que definiste en el Paso 3 (ej: mi_clave).

3. Una vez adentro, haz clic en el menú superior Bases de datos y verifica que exista la base de datos creada automáticamente (mi_base).

📷 Entregable 2: Captura de pantalla del navegador mostrando el panel principal de phpMyAdmin con tu sesión iniciada con éxito.
