🌐 Publicación Web Personalizada en un Contenedor Podman

🔍 Consulta tu Puerto Asignado

Escribe tu usuario del servidor para ver cuál es tu puerto asignado:

Paso 1: Auditar y Limpiar el Puerto

Antes de arrancar, debes comprobar si tu puerto está ocupado por algún servicio o prueba anterior.

1. Revisa el estado de tu puerto (reemplaza PUERTO por el número asignado):

sudo ss -tulpn | grep ':PUERTO'

2. Si la consulta devuelve algún proceso activo en ese puerto, libéralo inmediatamente ejecutando:

sudo fuser -k PUERTO/tcp

3. Vuelve a ejecutar la comprobación para asegurarte de que tu puerto quedó totalmente desocupado.

Paso 2: Crear la Carpeta y tu Sitio Web en el Servidor

1. En tu carpeta de usuario dentro del servidor, crea un directorio llamado web_podman.

2. Dentro de la carpeta web_podman, crea un archivo llamado index.html.

3. Edita el archivo index.html e incluye un título principal (<h1>) que contenga tu nombre y el número de puerto que te corresponde.

Paso 3: Encender el Contenedor para Publicar tu Web

Para publicar tu página web usando Podman, debes ejecutar el siguiente comando modificando dos datos:

  • Cambia PUERTO por el número asignado a tu usuario.
  • Asegúrate de poner la ruta correcta a tu carpeta /home/TU_USUARIO/web_podman.
podman run -d -p PUERTO:80 --name mi_web -v /home/TU_USUARIO/web_podman:/usr/share/nginx/html:Z nginx
📷 Entregable 1: Captura de pantalla de la terminal mostrando la ejecución del comando.

Paso 4: Verificación en el Navegador

1. Prueba primero desde la consola enviando una petición local:

curl http://localhost:PUERTO/

2. Abre el navegador web en tu computadora e ingresa la IP del servidor junto con tu puerto:

http://IP_DEL_SERVIDOR:PUERTO/
📷 Entregable 2: Captura de pantalla del navegador cargando con éxito tu sitio web personalizado.

Paso 5: Modificación en Vivo del Sitio Web

1. Edita nuevamente tu archivo index.html en el servidor agregando un párrafo (<p>) debajo del título principal con el siguiente texto de ejemplo:

<p>Página modificada en vivo mediante el volumen del contenedor Podman.</p>

2. Guarda los cambios en el archivo y recarga la página en tu navegador web (presionando F5 o Ctrl+R).

📷 Entregable 3: Captura de pantalla del navegador cargando con éxito tu sitio web personalizado.
