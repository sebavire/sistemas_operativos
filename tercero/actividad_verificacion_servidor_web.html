🔍 Actividad: Verificación de Servidor Web (systemctl y curl)

Objetivo: Aprender a comprobar el estado de un servicio en el servidor y diagnosticar la respuesta de las páginas web desde la propia terminal.

Parte 1: Estado del servicio web con systemctl

📋 Paso 1: Inspeccionar el servicio Apache

En la terminal, ejecutá el siguiente comando para ver la información del servidor web:

systemctl status httpd

✍️ Observá la pantalla y respondé:
  • En la línea Active:, ¿qué texto aparece en verde? (Ejemplo: active (running)).
  • ¿Podés identificar desde qué día o fecha está encendido el servidor?

Parte 2: Probando la red local con curl

📋 Paso 2: Consultar tu página pública

Para ver qué responde el servidor a tu carpeta web, usá el comando curl -I agregando tu ruta al final:

curl -I http://localhost/tu_usuario/

✍️ Mirá la primera línea que devuelve la terminal (empieza con HTTP/1.1):
¿Qué número aparece al lado de HTTP/1.1? (Ese número significa que la página existe y cargó correctamente).

📋 Paso 3: Probar un archivo que NO existe

Ahora intentá consultar con curl -I un archivo que no hayas creado, por ejemplo:

curl -I http://localhost/tu_usuario/archivo_falso.txt

✍️ Compará la salida:
¿Qué número aparece ahora en la primera línea? ¿Qué creen que significa ese número cuando navegamos en internet?

📋 Paso 4: Provocar un error de permisos (Simulación)

  1. Quita los permisos de lectura a tu carpeta web ejecutando:
    chmod 000 /var/www/html/tu_usuario
  2. Vuelve a probar el comando:
    curl -I http://localhost/tu_usuario/
  3. Anotá el número nuevo que aparece en la primera línea (significa "Acceso Prohibido").
  4. Restablece los permisos de tu carpeta ejecutando:
    chmod 755 /var/www/html/tu_usuario
