🌐 Actividad: Conectar Sitio Web (PHP) a la Base de Datos

En esta actividad desplegaremos un tercer contenedor con un servidor web en PHP que leerá e imprimirá datos en tiempo real desde la base de datos que creamos antes.

Paso 1: Crear la Tabla de Datos en phpMyAdmin

1. Entra a tu phpMyAdmin desde el navegador (http://192.168.2.245:TU_PUERTO/).

2. Selecciona tu base de datos mi_base en el menú de la izquierda.

3. Haz clic en la pestaña SQL superior, pega las siguientes sentencias y presiona Continuar:

CREATE TABLE IF NOT EXISTS productos ( id INT AUTO_INCREMENT PRIMARY KEY, nombre VARCHAR(100) NOT NULL, categoria VARCHAR(50) NOT NULL, precio DECIMAL(10,2) NOT NULL, stock INT NOT NULL ); INSERT INTO productos (nombre, categoria, precio, stock) VALUES ('Servidor RACK 2U', 'Hardware', 1450.00, 4), ('Switch Administrable 24p', 'Redes', 320.50, 12), ('Router Gigabit Dual Band', 'Redes', 85.00, 25), ('Disco SSD NVMe 1TB', 'Almacenamiento', 110.00, 18), ('Cable UTP Categoria 6 (305m)', 'Cableado', 95.00, 8);

Paso 2: Crear el Archivo PHP en tu Servidor

1. Crea una carpeta para tu sitio web llamada sitio_web_php

2. Dentro de la misma, crea un archivo llamado index.php

3. Copia el siguiente código, pégalo en el archivo y ajusta la variable $password si cambiaste tu clave:

Paso 3: Desplegar el Contenedor Web en Podman

1. Ejecuta el contenedor web mapeando la carpeta creada al servidor Apache interno:

podman run -d -p PUERTO_WEB:80 --name web_PUERTO_WEB -v ~/sitio_web_php:/var/www/html:Z php:8.2-apache

(Ejemplo si tu puerto es 8085, usas 9085 de puerto web: podman run -d -p 9085:80 --name web_8085 -v ~/sitio_web_php:/var/www/html:Z php:8.2-apache).

2. Habilita el conector de MySQL dentro del contenedor PHP (solo se ejecuta una vez):

podman exec -it web_PUERTO_WEB docker-php-ext-install mysqli

Paso 4: Verificación Final

Abre en el navegador la dirección: http://192.168.2.245:PUERTO_WEB/

Si todo está correcto, verás la tabla con los productos traídos desde MariaDB.
