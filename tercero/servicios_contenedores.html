🐳 Práctica: Publicación de Servicios con Contenedores

💡 ¿Qué es un Contenedor y para qué sirve?

Un contenedor es un entorno aislado que empaqueta una aplicación completa (en este caso, un servidor web Nginx) junto con todas sus dependencias. Esto permite ejecutar servicios independientes sin modificar el sistema operativo base del servidor.

Para acceder al servicio web que se ejecuta dentro del contenedor, se enlaza el puerto personal asignado en el servidor real hacia la aplicación en el contenedor:

Servidor Rocky Linux
(Sistema Operativo Base)

Puerto del Servidor
(ej: 8082)
── Enlaza a ──►
📦 CONTENEDOR
(Entorno Aislado)

Servidor Web (Nginx)
Aplicación Web Lista

Paso 1: Desplegar el Contenedor

1. Ejecuta el comando para encender el contenedor Nginx (reemplaza PUERTO por el número asignado, ej: 8082):

podman run -d -p PUERTO:80 --name mi_web_PUERTO nginx
📷 Entregable 1: Captura de pantalla de la terminal tras ejecutar el comando anterior.

Paso 2: Auditar el Servicio Nginx

1. Verifica la tabla de puertos en el servidor:

sudo ss -tulpn | grep ':PUERTO'

2. Consulta las cabeceras HTTP que responde el contenedor:

curl -I http://localhost:PUERTO/
✍️ Responde a partir de la salida del comando curl:
  • ¿Qué texto figura en la línea Server:?
📷 Entregable 2: Captura de pantalla con el resultado del comando curl funcionando.

Paso 3: Detener y Eliminar el Contenedor

1. Detén la ejecución del contenedor:

podman stop mi_web_PUERTO

2. Elimina el contenedor del sistema:

podman rm mi_web_PUERTO
✍️ Comprobación final:
Ejecuta nuevamente sudo ss -tulpn | grep ':PUERTO'. Comprueba que el puerto asignado volvió a quedar libre.
