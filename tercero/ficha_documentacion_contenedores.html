  • Tu puerto de Servidor Web PHP: 90XX
  • Nombre de la red interna de Podman: mi_red
  • Nombre del contenedor de Base de Datos: db_80XX
  • Nombre del contenedor Web: web_90XX
  • Ruta local del sitio web: ~/sitio_web_php
  • Ruta local de la base de datos: ~/datos_db

Parte 2: Comandos

Escribe en tu documento la secuencia exacta de comandos sustituyendo las palabras clave por TUS números reales de puerto y nombres.

  1. Crear la red interna:
    podman network create mi_red
  2. Desplegar la Base de Datos MariaDB:
    podman run -d --net mi_red --name db_PUERTO -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=mi_base -v ~/datos_db:/var/lib/mysql:Z mariadb
  3. Desplegar phpMyAdmin:
    podman run -d --net mi_red -p PUERTO:80 --name admin_PUERTO -e PMA_HOST=db_PUERTO phpmyadmin
  4. Desplegar el Servidor Web PHP:
    podman run -d --net mi_red -p PUERTO_WEB:80 --name web_PUERTO_WEB -v ~/sitio_web_php:/var/www/html:Z php:8.2-apache
  5. Habilitar la extensión MySQLi en PHP:
    podman exec -it web_PUERTO_WEB docker-php-ext-install mysqli
  6. Reiniciar el contenedor Web PHP:
    podman restart web_PUERTO_WEB
