⚡ Actividad: Recuperación y Verificación

Objetivo: Probar la validez de las copias de seguridad realizando una restauración simulada de archivos y automatizando la localización del último respaldo mediante variables en un script.

📌 Comandos y Estructuras de Referencia

Consulta esta sintaxis general para resolver las actividades planteadas a continuación:

Acción / Concepto Sintaxis de referencia
Ver contenido de un .tar.gz tar -tzf /ruta/archivo.tar.gz
Descomprimir en un destino específico tar -xzf /ruta/archivo.tar.gz -C /ruta/destino/
Guardar el archivo más reciente en una variable archivo=$(ls -t /carpeta/*.tar.gz | head -n 1)

📋 PARTE 1: Restauración manual de un respaldo

Simularemos un escenario de recuperación extrayendo una copia de seguridad en una carpeta de prueba.

✍️ Consigna:

  1. Crea una carpeta de prueba llamada recuperado dentro de tu directorio web personal (/var/www/html/tu_usuario/).
  2. Elige uno de los archivos .tar.gz que tengas guardados en tu carpeta de backups y ejecuta el comando para listar su contenido en la terminal sin descomprimirlo.
  3. Restaura el contenido de ese archivo .tar.gz **únicamente dentro de la carpeta recuperado** creada en el paso 1.
  4. Abre tu navegador web y accede a la dirección de tu carpeta recuperado/ para confirmar que los archivos restaurados están visibles correctamente.

📋 PARTE 2: Script de restauración automática

En lugar de buscar y escribir manualmente el nombre del archivo de respaldo, crearemos un script que identifique el último respaldo creado y lo descomprima de forma automática.

✍️ Consigna:

  1. Crea un script llamado restaurar_ultimo.sh usando el editor nano.
  2. Escribe el script para que realice las siguientes tareas al ejecutarse:
    • Muestre un mensaje en pantalla indicando que se inicia la restauración.
    • Busque cuál es el archivo .tar.gz más reciente dentro de tu carpeta de respaldos (/var/www/html/tu_usuario/backups/) y guarde su ruta dentro de una variable llamada ultimo_backup.
    • Descomprima ese último respaldo guardado en la variable dentro de tu carpeta recuperado/.
    • Muestre un mensaje final informando que la restauración ha concluido.
  3. Otorga los permisos de ejecución necesarios al script.
  4. Ejecútalo en la terminal y comprueba desde el navegador web que los archivos actualizados se encuentran en tu carpeta recuperado/.
