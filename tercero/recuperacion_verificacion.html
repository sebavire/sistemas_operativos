⚡ Actividad: Recuperación y Verificación

Objetivo: Probar la validez de las copias de seguridad realizando una restauración simulada de archivos y creando un script para verificar el estado de los respaldos.

📌 Concepto clave

Para comprobar que un archivo .tar.gz es válido y no está corrupto, debemos ser capaces de listar su contenido o extraerlo en un directorio de prueba.

📋 PARTE 1: Restauración de un respaldo

Simularemos un escenario de recuperación extrayendo tu copia de seguridad en una carpeta limpia.

  1. Crear una carpeta de prueba para la restauración:
    mkdir -p /var/www/html/usuario/recuperado
  2. Ver el contenido del respaldo sin descomprimirlo:
    El parámetro -t permite listar los archivos empaquetados dentro de un archivo .tar.gz:
    tar -tzf /var/www/html/usuario/backups/nombre_de_tu_backup.tar.gz
  3. Restaurar los archivos:
    Usa el comando tar -xzf junto con la opción -C para extraer todo el contenido dentro de la carpeta de prueba que creaste:
    tar -xzf /var/www/html/usuario/backups/nombre_de_tu_backup.tar.gz -C /var/www/html/usuario/recuperado/
  4. Verificar la recuperación:
    Ingresa desde el navegador web para confirmar que tus archivos se restauraron correctamente:
    http://192.168.2.245/usuario/recuperado/

📋 PARTE 2: Script de verificación del último backup

Ejemplo de comando para ver el archivo más reciente de un directorio:

Para mostrar los detalles del archivo creado más recientemente, podemos ordenar por fecha con ls -lht y filtrar las primeras líneas con head -n 2 (la cabecera y el primer archivo):

ls -lht /carpeta/ejemplo/ | head -n 2

✍️ Consigna de la Parte 2:

  1. Crea un script llamado verificar.sh.
  2. El script debe mostrar un título (usando echo) que diga: "=== ESTADO DEL ÚLTIMO RESPALDO ===".
  3. A continuación, el script debe ejecutar el comando correspondiente para listar **únicamente el último archivo de respaldo** que se generó dentro de tu carpeta /var/www/html/usuario/backups/.
  4. Otorga permisos de ejecución al script (chmod 755).
  5. Ejecuta el script guardando su resultado en un archivo llamado estado_backup.txt dentro de tu carpeta web:
    /var/www/html/usuario/verificar.sh > /var/www/html/usuario/estado_backup.txt
  6. Verifica desde el navegador ingresando a http://192.168.2.245/usuario/estado_backup.txt.

📌 Resumen de comandos de la actividad

Comando ¿Qué hace?
tar -tzf archivo.tar.gz Muestra el contenido de un respaldo sin descomprimirlo
tar -xzf archivo.tar.gz -C /ruta/ Extrae y restaura el contenido del respaldo en la ruta indicada
ls -lht /ruta/ | head -n 2 Muestra únicamente el archivo más reciente de una carpeta con su tamaño y fecha
