📦 Actividad: Copias de Seguridad (Backups)

Objetivo: Crear un script en Bash que comprima de forma automatizada la carpeta web personal, incluyendo la fecha y hora en el nombre del archivo de respaldo, y programar su ejecución periódica mediante cron.

📌 Recordatorio de comandos esenciales

Conectarse al servidor:

ssh usuario@192.168.2.245

Crear una carpeta para guardar los respaldos:

mkdir -p /var/www/html/usuario/backups

Dar permisos de ejecución a un script:

chmod 755 /var/www/html/usuario/backup.sh

📋 PARTE 1: Comandos clave para la actividad

Para construir el script de respaldo vas a utilizar los siguientes comandos y herramientas:

  1. Uso de variables y fechas en Bash:
    Para que cada copia de seguridad sea única y no sobrescriba la anterior, podemos capturar la fecha actual en una variable:
    FECHA=$(date +%Y-%m-%d_%H-%M)
    echo "La fecha actual es: $FECHA"
  2. Compresión de carpetas con tar y gzip:
    El comando tar -czf permite empaquetar y comprimir un directorio completo en un solo archivo .tar.gz.
    tar -czf /ruta/destino/archivo_destino.tar.gz /ruta/origen/carpeta_a_comprimir

📋 PARTE 2: Crear el script de respaldos

Crea un script llamado backup.sh dentro de tu carpeta web o de trabajo.

Requisitos que debe cumplir el script:

  • Definir una variable con la fecha actual en formato Año-Mes-Día_Hora-Minuto.
  • Mostrar un mensaje por pantalla indicando que el proceso de respaldo ha comenzado.
  • Ejecutar el comando tar -czf para comprimir todo el contenido de tu carpeta web /var/www/html/usuario/ y guardar el resultado dentro de la carpeta de respaldos /var/www/html/usuario/backups/.
  • El archivo generado debe nombrarse siguiendo el formato: backup_FECHA.tar.gz (reemplazando FECHA por el valor de la variable definida).
  • Mostrar un mensaje final indicando que el respaldo fue completado con éxito.

📤 Subir el script, darle permisos y probarlo

  1. Sube o crea el script backup.sh en el servidor.
  2. Otórgale permisos de ejecución con chmod 755.
  3. Ejecutá el script manualmente en la terminal:
    /var/www/html/usuario/backup.sh
  4. Verifica que dentro de la carpeta /var/www/html/usuario/backups/ se generó correctamente el archivo comprimido con la fecha del momento. Puedes listarlo con:
    ls /var/www/html/usuario/backups/

⏱️ PARTE 3: Programar la automatización en Cron

Programa tu script backup.sh en cron para que se ejecute automáticamente sin intervención manual.

  1. Abre el editor de crontab con crontab -e.
  2. Agrega una nueva regla para que el script de respaldo se ejecute automáticamente cada 2 minutos (para probar en clase) o todos los días a las 02:00 AM.
  3. Espera el tiempo necesario y comprueba en la carpeta de respaldos que se van generando los nuevos archivos comprimidos con sus respectivas marcas de tiempo.
  4. Modifica la regla en crontab para que se ejecute todos los días a las 02:00 AM.

🎯 Extra / Desafío

Mantenimiento automático de espacio:

Si los respaldos se ejecutan indefinidamente, el disco del servidor se llenará. Agrega al final de tu script backup.sh una línea utilizando el comando find para borrar automáticamente los archivos .tar.gz con más de 10 días de antigüedad en tu carpeta de respaldos:

find /var/www/html/usuario/backups/ -name "*.tar.gz" -mtime +10 -exec rm {} \;
